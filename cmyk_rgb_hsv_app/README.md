# Лабораторная работа 1 — CMYK / RGB / HSV

Локальное веб-приложение для работы с тремя цветовыми моделями:
- RGB
- CMYK
- HSV

При изменении любой координаты остальные две модели пересчитываются автоматически.

## Требования

Python 3.9+.

Дополнительные библиотеки не нужны.

## Запуск

1. Скачайте репозиторий:
```bash
git clone https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
cd ВАШ-РЕПОЗИТОРИЙ
```

2. Запустите:
```bash
py server.py
```
3. Откройте в браузере:

http://127.0.0.1:8000

Остановить сервер: `Ctrl+C`
.
## Формулы

### RGB → CMYK

После нормализации RGB в диапазон 0..1:

`K = 1 - max(R, G, B)`

при `K < 1`:

`C = (1 - R - K) / (1 - K)`

`M = (1 - G - K) / (1 - K)`

`Y = (1 - B - K) / (1 - K)`

### CMYK → RGB

`R = 255 × (1 - C) × (1 - K)`

`G = 255 × (1 - M) × (1 - K)`

`B = 255 × (1 - Y) × (1 - K)`

### RGB ↔ HSV

Используются стандартные преобразования через максимум, минимум и разницу компонент RGB.
